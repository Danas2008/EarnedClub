# Earned Club Agent Instructions

Before making code, design, documentation, deployment, or test changes in this repository:

1. Read `docs/earned-plan.md`.
2. Treat `docs/earned-plan.md` as the shared source of truth for product direction, routes, scoring, verification rules, workflows, risk notes, and current change history.
3. Keep changes consistent with the product rules and current active disciplines described there.
4. When a meaningful change affects product behavior, routes, models, scoring, verification, dashboard/profile, homepage, onboarding, deployment, email, admin workflows, SEO, or tests, update `docs/earned-plan.md` in the same working session.
5. If no plan update is needed, say why in the final response.

Do not let the plan drift from the code. A task is not finished until any needed plan update is included.
